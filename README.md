# MetalPipe
A loud pipe of metal will fall to the ground each time you click (Press ESC to stop it), compile it using this command: "python -m PyInstaller --onefile --add-data="ThePipe.ogg:." MetalPipe.py" made to work both in Linux and Windows!

It also runs directly with "python3 MetalPipe.py" but make sure the audio from ThePipe.ogg are in the same folder as the main python file.
This last ".ogg" file can be replaced by any other .ogg file but make sure to change the name in the code or to use the same one as "ThePipe.ogg". That's it, have fun :D!
